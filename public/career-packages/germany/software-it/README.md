# Germany Tech Job Application Kit — Software / IT

Welcome to the Germany-focused application kit for software and IT professionals.

## What this package is for

Use this kit to build a clear, market-aware application for German technology roles. It is designed for international applicants and covers:

- CV preparation
- Cover-letter customization
- Job-description analysis
- Application tracking
- Interview/application workflow
- Optional AI-assisted refinement

This kit is guidance and templates, not legal or immigration advice.

## Included

1. Germany CV Guidance
2. Professional CV Template
3. Senior / Leadership CV Template
4. Cover Letter Templates
5. Job Description Worksheet
6. Application Checklist
7. Application Tracker
8. AI Prompt Pack

## Target roles

The examples are especially useful for:

- Software Engineer
- Tech Lead
- Solution Architect
- Engineering Manager

## Recommended workflow

1. Select a target role.
2. Copy the CV template that best matches your experience.
3. Extract requirements from the job description using the worksheet.
4. Tailor the CV to the role without inventing experience.
5. Adapt the cover letter to the employer and position.
6. Run the final checklist.
7. Record the application in the tracker.
8. Use the AI prompts only for refinement and review.

## Important

There is no single universally mandatory CV layout for every German employer. Prioritize a professional, readable, machine-readable document with accurate information and a structure that makes relevant experience easy to find.
